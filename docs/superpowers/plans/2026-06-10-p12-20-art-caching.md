# P12-20 Art Caching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Workbox runtime cache rule so card art (`.jpeg` files in `/cards/`) is cached on first view and served from cache offline.

**Architecture:** The existing `vite-plugin-pwa` Workbox config in `vite.config.ts` already precaches JS/CSS/HTML but omits JPEG. We add a single `runtimeCaching` entry using `StaleWhileRevalidate` — art is cached on first fetch, returned from cache immediately on subsequent requests, and silently refreshed in the background when connected. No component changes required.

**Tech Stack:** Vite, vite-plugin-pwa, Workbox (bundled with vite-plugin-pwa), TypeScript.

---

### Task 1: Add runtime cache rule for card art

**Files:**
- Modify: `vite.config.ts`

**Context:**
The current `workbox` block in `vite.config.ts` is:
```ts
workbox: {
  globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}']
}
```

Card art lives at `/cards/xxx.jpeg` (108 files, 37MB total). The `globPatterns` only handles precaching at build time — it omits `.jpeg` entirely. We add `runtimeCaching` alongside it.

- [ ] **Step 2: Add the `runtimeCaching` block**

Replace the `workbox` block with:
```ts
      workbox: {
        globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
        runtimeCaching: [
          {
            urlPattern: /\/cards\/.*\.jpe?g$/,
            handler: 'StaleWhileRevalidate',
            options: {
              cacheName: 'card-art-v1',
              expiration: {
                maxEntries: 200,
                maxAgeSeconds: 60 * 60 * 24 * 30, // 30 days
              },
            },
          },
        ],
      },
```
