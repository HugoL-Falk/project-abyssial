D2 colour iterations

All four use the same glass brilliant-cut structure (conic facets, cool specular, transmission). Only the colour palette changes. Doom was your reference — so every tier below is tuned to the same luminance depth.
Original. Current D2 deep palette — richer than before but still relatively bright.
Mid. Exactly halfway between Original and Moody. Rich saturated hues, meaningfully darker than Original.
Moody. All tiers tuned to Doom's depth. Crimson, emerald, sapphire etc as very dark jewels.
Shadow. Half-step darker than Moody. Borders on obsidian — hue is a hint, not a statement.
Ink. Near-black. Conic facets barely visible — only the specular gives it life.

Ultra 3D / Glass pass

Moody palette + pushed glass effects: pure-white centre specular, chromatic aberration ring at specular edge, secondary internal reflection mid-gem, strong edge catch. Side-by-side with Moody for comparison.
Moody. Reference — same as column 2 above.
Ultra 3D. White-hot specular core → chromatic fringe (blue tint at edge of specular) → secondary ghost highlight inside the body → strong bright edge catch.
